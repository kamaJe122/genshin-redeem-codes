# 原神兌換碼簿

原神國際服／亞服（Asia）兌換碼清單，單一 HTML 檔、不需安裝。

## 功能
- 每組兌換碼都有一鍵兌換連結（`https://genshin.hoyoverse.com/zh-tw/gift?code=兌換碼`）
- 點「前往兌換」自動記錄已兌換與兌換日期時間（存在瀏覽器 localStorage）
- 兌換失敗可「取消標記」，也能一鍵重設所有紀錄
- 直播碼失效倒數計時
- 分享：複製全部連結、LINE 分享、單組分享

## 使用
直接用瀏覽器打開 `index.html`，或開啟 GitHub Pages 後用網址瀏覽。

## 資料
兌換碼查核時間：2026/10/26（UTC+8）。兌換碼常會過期，實際以官方兌換結果為準。
